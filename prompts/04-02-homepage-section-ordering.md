# Task 04-02 — Homepage Section Ordering and Visibility

Inspect the homepage architecture, appearance settings schema, and dashboard UI conventions.

Build an admin editor to enable/disable and reorder approved homepage modules: spotlight, stats/completeness, showcase tabs, timeline highlights, and explorer/search teaser. Use accessible drag-and-drop or keyboard-operable move controls. Persist only to draft settings and validate unique section IDs, supported modules, and sensible ordering on the server.

Do not allow arbitrary component names or executable code to be stored. Ensure public layout uses the published configuration. Add tests for malformed order data and update state.
