# Task 03-01 — Hero CRUD

Inspect schema, admin auth, draft service, form conventions, and validation libraries before implementation.

Build the private hero management workflow for create, edit, view, and delete/archive as supported by the schema. Cover hero name, primary/secondary role, specialty, portrait/media reference, mastery level, total matches, win rate, and signature/favorite status. Validate required fields and numeric bounds on the server as well as in the UI. Protect referenced media and avoid direct browser writes that bypass authorization.

Keep this task limited to heroes; do not build skin CRUD or bulk import. Include loading, empty, success, and error states and tests for validation/auth where feasible. Update state.
