# Task 01-02 — Design Tokens and Typography

Read the master protocol, project state, architecture decisions, and inspect the current app before editing.

Implement the approved design foundation using the project's existing Tailwind version and conventions:
- Dark-first and light theme tokens.
- Stable semantic tokens for background, surface, text, muted text, borders, focus, and primary/secondary accents.
- Consistent rarity/role accent tokens for gold, purple, blue, and emerald.
- Geometric display font and readable sans-serif body font, using reliable local/system fallbacks.
- Tabular numerals for statistics.
- Accessible focus indicators and reduced-motion-aware defaults where relevant.

Do not build page sections or dashboard features in this task. Avoid hard-coded colors scattered across components.

Acceptance criteria: tokens work in both themes, theme switching foundation is documented, typography is applied consistently, and lint/typecheck/build checks are run when available. Update project state and prompt index with evidence.
