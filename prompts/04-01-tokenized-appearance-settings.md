# Task 04-01 — Tokenized Appearance Settings

Inspect the design tokens and draft data service first.

Build admin controls for theme preset, primary/secondary accents, typography scale, container width/spacing, and related approved visual tokens. Validate choices against an allowlist and save them to draft settings only. Preview changes safely without letting untrusted values inject scripts or arbitrary CSS. Keep text contrast and keyboard accessibility in mind.

Do not build section ordering or custom CSS in this task. Ensure public pages read appearance settings from the published release, not live drafts. Add validation tests and update state.
